Methods description templates
==============================

Put a plain text file (.txt) here and it appears in the Details and notes
dialog's "Use a template..." menu, next to the Methods box (Workbook > Details
and notes...). Choosing one replaces the whole Methods box with the file's
contents; the file name (without ".txt") is what shows in the menu.

Two starting templates are included, for the two instrument families this
app reads directly (Thermo Avantage, Kratos ESCApe/Vision). Edit the wording,
add your own instrument's file, or drop in a template for any other system.
